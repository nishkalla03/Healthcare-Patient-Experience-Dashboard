# Healthcare Patient Experience Dashboard

## Overview

This repository showcases a **group data visualization project** that analyzes outpatient clinic operations using **RFID timestamp data** and **electronic patient survey data**. The project focuses on identifying patient flow patterns, waiting times, operational performance, and patient satisfaction through interactive visualizations.

> **Note:** The dataset used in this project is publicly available from Mendeley Data. Dashboard screenshots are shared for portfolio purposes.

---

## My Contribution

Although this was a **group project**, my primary responsibility was to **design and develop the interactive dashboard**.

The overall project workflow included:

- Data exploration
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Dashboard design and development *(My Contribution)*
- Data storytelling and presentation

---

## Dashboard Overview

The dashboard consists of **four interactive pages**.

### 1. Healthcare Analytics Overview

Provides an overview of outpatient clinic performance, including:

- Average Patient Visit Time
- Patient Satisfaction Trends
- Visit Duration Analysis
- Operational Performance Summary

---

### 2. Executive Summary

Key performance indicators (KPIs), including:

- Total Patients
- Average Visit Time
- Average Doctor Waiting Time
- Overall Satisfaction Index (OSI)
- Patient Satisfaction Distribution

---

### 3. Operational Performance Analysis

Analyzes outpatient operational efficiency through:

- Patient Volume Trends
- Average Visit Duration
- Peak Patient Arrival Hours
- Waiting Time Analysis
- Patient Flow Visualization

---

### 4. Patient Satisfaction Analysis

Explores factors influencing patient satisfaction using:

- Waiting Time Analysis
- Satisfaction Score Distribution
- Survey Response Comparison
- Service Quality Insights

---

## Visualizations Used

The dashboard includes a variety of visualization techniques, including:

- KPI Cards
- Decomposition Tree
- Line Chart
- Area Chart
- Scatter Plot
- Heatmap
- Bubble Chart
- Sankey Diagram
- Survey Matrix
- Interactive Filters

---

## Key Findings

- Patient volume increased during peak periods, reflecting higher clinic demand.
- Average visit duration generally decreased over time, indicating improved operational efficiency.
- Most patients experienced relatively short waiting times.
- Overall patient satisfaction remained positive, with an average Overall Satisfaction Index (OSI) of **4.04**.
- Waiting time alone was not the primary factor influencing patient satisfaction, suggesting that other aspects of service quality also contribute to patient experience.
